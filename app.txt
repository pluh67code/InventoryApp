KEYBOARD STORE

Per Keyboard:
    - id  
    - name
    - amount in stock 
    - stock status
    - brand 
    - size (60%, 75%, 80%, 100%)
    - switch type (silent, thocky) 
    - connection type (wired or wireless)


Functionality:
    index:
        - welcome + about the site
        - view keyboards (enters the store)
    store:
        - shows all keyboards
        - add keyboard button
        - delete keyboard on each keyboards UI
        - view keyboard details button on each keyboards UI
        - update keyboard info when u enter the details page for a kb
        - back to home button
